# 🎨 AI绘画提示词优化器

## 功能介绍

本脚本可以将简单的描述转化为专业级的AI绘画提示词，支持Midjourney、Stable Diffusion、DALL-E等平台。

## 使用方法

\\\ash
python scripts/prompt_optimizer.py --input \"一只可爱的猫\" --style \"水彩画\" --output prompt.txt
\\\

## 提示词模板

### 通用增强模板
- **基础描述** → **专业提示词**
- \"一只猫\" → \"一只可爱的橘猫，水彩画风格，柔和色彩，细节丰富，艺术感，高清，8K\"

### 风格库
- 写实摄影、水彩画、油画、像素艺术、赛博朋克、奇幻风格等50+种风格
